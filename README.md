# BitHub

This web-based tool simplifies and streamlines csv to SQL data ETL process.

## Description

Most small to medium sized companies struggle with different tools to accomplish the basic data flow from csv to SQL. This tool visualizes the ETL process, and takes care of the scheduling.

## Getting Started

### Dependencies
- npm 22.14.0 (the frontend use Volta to target the correct version)
- NET 9.0 library

### Launch in VS Code
Open the BitHub.code-workspace file in the VS Code. The editor should automatically build the frontend and backend on launch.
